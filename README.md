# Luma update feed

Public binary/update metadata repository for Luma and Luma Kids.

- `adult/` — adult Luma update manifest
- `kids/` — Luma Kids update manifest

This repository must never contain application source code, private signing keys, API keys, user profiles, AppData, Family data, backups, or credentials. Installers and signatures are published as GitHub Release assets; each app reads only its own channel manifest.
